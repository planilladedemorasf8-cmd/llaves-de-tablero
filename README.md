# 🔑 Control de Llaves - Tableros 1 y 2 (A y B)

Aplicación web interactiva para la búsqueda predictiva, control visual y administración del inventario de llaves de los Tableros 1 y 2 (Ganchos A y B).

---

## 🚀 Características

- **🔍 Buscador Predictivo**: Búsqueda instantánea por nombre de dependencia, número de gancho o código de tablero (ej. `29`, `Boletería`, `Pañol`, `Baño`, `1-B`).
- **🏷️ Filtros Rápidos**: Acceso directo con un solo clic a las categorías más consultadas.
- **📋 Vista de Tableros Visuales**: Visualización de los tableros A y B con todos sus ganchos y estados.
- **➕ Gestión de Llaves**: Botón **Nueva Llave** y opción de editar directamente cualquier gancho.
- **💾 Persistencia Automática**: Todos los cambios y nuevas llaves se guardan en el almacenamiento local del navegador (`localStorage`).
- **🌐 Listo para GitHub Pages**: No requiere compilación previa, servidores ni dependencias complejas.

---

## 🌐 Publicar en GitHub Pages (Paso a Paso)

1. Sube este repositorio a tu cuenta de **GitHub**.
2. En el repositorio de GitHub, entra a la pestaña **Settings** (Configuración).
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección **Branch**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
5. Haz clic en **Save** (Guardar).
6. En unos segundos, GitHub te proporcionará la URL pública para acceder a tu sitio web desde cualquier dispositivo (computadora, tablet o celular).

---

## 💻 Uso Local

Puedes abrir directamente el archivo `index.html` o `Control_de_Llaves_OFFLINE.html` con cualquier navegador moderno (Chrome, Edge, Firefox).
