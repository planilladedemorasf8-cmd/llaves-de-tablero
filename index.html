☁️ Sincronización Multi-PC en Tiempo Real

GitHub Pages guarda los datos en la memoria local de cada navegador (localStorage). Para que todas las computadoras compartan las mismas llaves y cambios en tiempo real, conecta una base de datos gratuita en la nube con Firebase Realtime Database.

📋 ¿Cómo crear tu base de datos gratis en 2 minutos?
  1. Entra a console.firebase.google.com con tu cuenta Google y crea un proyecto.
  2. En el menú ve a Compilación > Realtime Database y haz clic en Crear base de datos.
  3. En Reglas selecciona "Comenzar en modo de prueba" (permite lectura y escritura).
  4. Copia la URL que aparece arriba (terminada en .firebaseio.com), pégala aquí y guarda.
⚙️ Ajustes de Acceso (Usuario y Clave)

Modifica las credenciales de acceso al sistema. Si Firebase está conectado, el cambio se sincronizará automáticamente para todas las computadoras.
